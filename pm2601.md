### 1. Постановка задачи

> Программа получает на вход 5 натуральных чисел X-диаметр отверстия и  A, B, C, D, которые являются диаметрами бусинок. Нужно найти количество бусинок, которые пролезут через 
отверстие диаметром X.


Данную задачу можно разделить на 2 подзадачи: ввод чисел с клавиатуры и выбор подходящих по размеру бусинок.

В первой подзадачи нужно просто вывести 5 натуральных чисел клавиатуры.

Во второй подзадаче нужно определить бусинки которые влезают в отверстие и вывести.


### 2. Входные и выходные данные

#### Данные на вход

На вход программа должна получать 5 натуральных чисел.

|             | Тип                | min значение    | max значение   |
|-------------|--------------------|-----------------|----------------|
| X (Число 1) | Целое число        |        1        | не сказано     |
| A (Число 2) | Целое число        |        1        | не сказано     |
| B (Число 3) | Целое число        |        1        | не сказано     |
| C (Число 4) | Целое число        |        1        | не сказано     |
| D (Число 5) | Целое число        |        1        | не сказано     |

#### Данные на выход

Количество подходящих под условие бусинок
|         | Тип                         | min значение | max значение |
|---------|-----------------------------|--------------|--------------|
| Число 1 | Целое неотрицательное число |      0       |       4      |

### 3. Выбор структуры данных

Программа получает 5 натуральных чисел. Поэтому для их хранения
можно выделить 5 переменных (`x`, `a`, `b`, `c`, `d`) типа `int`.
Также используем для подсчёта подходящих бусинок переменную `count` типа `int`.

|             | название переменной | Тип (в Java)| 
|-------------|---------------------|-----------  |
| X (Число 1) | `x`                 |    `int`    |
| A (Число 2) | `a`                 |    `int`    | 
| B (Число 3) | `b`                 |    `int`    |
| C (Число 4) | `c`                 |    `int`    | 
| D (Число 5) | `d`                 |    `int`    |
| Наш вывод   | `count`             |    `int`    |


### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**  
   На вход программа должна получать 5 натуральных чисел, обозначенных переменными (`x`, `a`, `b`, `c`, `d`).

2. **Сравнение чисел:**  
   Программа сравнивает значение `x` с переменными ( `a`, `b`, `c`, `d`). Если `x` больше переменной `a`, то программа прибавляет к переменной `count` + 1 и переходит к следующему шагу для
   работы с `b`. Если `x` меньше, то программа ничего не прибавляет к `count` и идёт выполняться дальше. 
   После сравнения `x` и `a` программа сравнивает `x` с `b`. Если `x` больше переменной `b`, то программа прибавляет к переменной `count` + 1 и переходит к следующему шагу для
   работы с `c`. Если `x` меньше, то программа ничего не прибавляет к `count` и идёт выполняться дальше.
   После сравнения `x` и `b` программа сравнивает `x` с `c`. Если `x` больше переменной `c`, то программа прибавляет к переменной `count` + 1 и переходит к следующему шагу для
   работы с `d`. Если `x` меньше, то программа ничего не прибавляет к `count` и идёт выполняться дальше.
   После сравнения `x` и `c` программа сравнивает `x` с `d`. Если `x` больше переменной `d`, то программа прибавляет к переменной `count` + 1 и переходит к следующему шагу для
   работы с `c`. Если `x` меньше, то программа программа выводит переменную `count` без изменений.

3. **Вывод результата:**  
   На экран выводится либо 0, либо 1, либо 2, либо 3, либо 4

### 5. Программа

```java

import java.util.Scanner; // чтобы работал вывод и ввод
public class Main {
    public static void main (String[] args){
        Scanner in=new Scanner(System.in);
        int x= in.nextInt(); // ввод новой переменной X
        int a= in.nextInt();// ввод новой переменной A
        int b= in.nextInt();// ввод новой переменной B
        int c= in.nextInt();// ввод новой переменной C
        int d= in.nextInt();// ввод новой переменной D
        int count=0; // ввод переменной, которая будет подсчитывать количество подходящих бусинок
        if (a<=0) //проверка на правильный ввод переменной
            System.out.println("Такого быть не может"); // вывод этой строки в случае если ввод неверный
        if (b<=0)//проверка на правильный ввод переменной
            System.out.println("Такого быть не может");// вывод этой строки в случае если ввод неверный
        if (c<=0)//проверка на правильный ввод переменной
            System.out.println("Такого быть не может");// вывод этой строки в случае если ввод неверный
        if (d<=0)//проверка на правильный ввод переменной
            System.out.println("Такого быть не может");// вывод этой строки в случае если ввод неверный
        if (x>a) // проверка на то проходит ли бусинка A в отверстие X
            if (a>0) // чтобы не считало неправильно введенные бусинки
                count+=1; //Если проходит прибавляем 
        if (x>b)// проверка на то проходит ли бусинка B в отверстие X
            if (b>0)// чтобы не считало неправильно введенные бусинки
                count+=1; //Если проходит прибавляем 
        if (x>c)// проверка на то проходит ли бусинка C в отверстие X
            if (c>0)// чтобы не считало неправильно введенные бусинки
                count+=1; //Если проходит прибавляем 
        if (x>d)// проверка на то проходит ли бусинка D в отверстие X
            if (d>0)// чтобы не считало неправильно введенные бусинки
                count+=1; //Если проходит прибавляем 
        System.out.println(count); // вывод
    }
}

```
